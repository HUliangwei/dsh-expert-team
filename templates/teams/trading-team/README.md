# 交易分析团队（trading-team）模板说明

- **模板类型**：专家团（teams/）
- **成员模板引用**：researcher / market-analyst / reviewer（templates/members/）
- **部署产物**：`trading-team-lead` + `trading-team-researcher` / `trading-team-analyst` / `trading-team-reviewer`
- **协作流程**：信息收集 → 技术面分析 → 复核风控 → 主理人整合建议

> 本模板的 4 阶段流程改编自 WorkBuddy 官方「交易分析团队」示例（原为 5 阶段：数据采集→多空辩论→交易决策→风险评估→最终报告），可作为 SOP 编排的参考样板。
